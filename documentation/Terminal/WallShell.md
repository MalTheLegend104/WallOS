# WallShell

WallOS now uses a (slightly modified) version of my terminal emulator/shell, [WallShell](https://github.com/MalTheLegend104/WallShell).
Refer to that for all documentation, it follows very closely to what is implemented as the kernel shell.

Everything else is documented in the actual source file, `src/kernel/klibc/terminal/wall_shell.c` (and the associated header).
